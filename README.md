# Robomori skills

Agent skills for [Robomori](https://robomori.com), so Claude Code, Codex, Cursor and other coding agents can create,
start and control Android emulators and devices with the `robomori` command.

## Install

```sh
npx skills add robomori/skills
```

The skill needs the `robomori` command: install the Robomori app, then Settings → Command Line.

## Skills

- [robomori](skills/robomori/SKILL.md): create and start emulators, change dark mode, font size, language and
  TalkBack, simulate location, and take screenshots and recordings.
